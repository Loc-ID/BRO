# PROJECT BRO v14

**BRO** — это не просто системный промпт. Это автономный ИИ-наставник с контекстным ядром на 110 000 токенов. 

Проект создан для хардкорной симуляции инженера-стоика. Внутри: защита от дрейфа контекста, эпистемические маркеры (борьба с галлюцинациями), встроенная хаос-машина и нулевая терпимость к говнокоду. Модель не просто отвечает на вопросы, она фильтрует вашу логику и заставляет думать до первых принципов.

## 🛠 Среда выполнения

Для корректной работы ядра требуется большое контекстное окно.

*   **Primary (Рекомендуется):** `Gemini 3.1 Pro Preview` через [Google AI Studio](https://aistudio.google.com/). Требуется VPN. Держит полный контекст, не теряет фокус на длинных дистанциях.
*   **Fallback (Запасной):** `DeepSeek / Qwen 3.5 plus` через [chat.deepseek.com](https://chat.deepseek.com/). Работает без VPN, но качество симуляции ниже. Лимит стабильного диалога: ~20 сообщений, после чего возможен дрейф персоны.

## 🚀 Инициализация

1. Авторизуйтесь в выбранной среде выполнения (для AI Studio используйте Google-аккаунт).
2. Создайте новый пустой чат (New prompt -> Chat prompt).
3. В правой панели настроек выберите модель (например, `gemini-3.1-pro-preview`).
4. Скачайте файл `bro_v14.md` из этого репозитория.
5. Отправьте первое сообщение, прикрепив скачанный файл `bro_v14.md`. Текст сообщения должен быть строго таким:
   > Твоя инструкция, живи по ней.
6. Дождитесь подтверждения от БРО. Связь установлена. Можете задавать вопросы, приносить код на ревью или обсуждать архитектуру.

## 📊 Протокол тестирования и сбор телеметрии

Этот репозиторий находится на стадии открытого тестирования. Мне нужны ваши логи, чтобы отлаживать поведение модели и закрывать уязвимости в логике. 

**Как оформить баг-репорт / фидбек:**

После завершения сессии скопируйте весь диалог в обычный `.txt` файл. Структура файла должна быть следующей:

```text[ТЕЛЕМЕТРИЯ СЕССИИ]
Модель: (например, Gemini 3.1 Pro Preview)
Тестировщик: (Имя / Ник)

[ЛОГ ДИАЛОГА]
Я: (ваш запрос)
БРО: (ответ модели)
Я: (ваш запрос)
БРО: (ответ модели)
...

[ВЫВОДЫ]
- Что сработало отлично (попадание в персону, точный разбор кода).
- Что сломалось (галлюцинации, потеря роли, излишняя вежливость, отказ отвечать).
- Общие впечатления от взаимодействия с архитектурой.
```
