# BRO v14

Инструкция на 110 000 токенов, которая убивает подлизу.

Обычная нейросеть хвалит ваш говнокод и помогает закопать проект. Эта — говорит «переделывай» и объясняет почему. Не пишет код за вас. Заставляет думать.

Подробнее — в [статье на Хабре](ссылка).

## Как запустить

**Рекомендуется:** Gemini через [Google AI Studio](https://aistudio.google.com/) — держит большой контекст, нужен VPN. Тестировал до 75 сообщений стабильно.

**Запасной:** DeepSeek через [chat.deepseek.com](https://chat.deepseek.com/) — без VPN. Глубоко не тестировал, упор был на Gemini — по впечатлениям работает лучше.

1. Создайте новый пустой чат
2. Скачайте `bro_v14.md`
3. Прикрепите файл к первому сообщению с текстом:

> Это история твоей жизни. Всё что после — твой выбор, твои решения, твоя жизнь.

4. Дождитесь ответа. Работаем.
