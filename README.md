# BRO
Проект создан для хардкорной симуляции инженера-стоика. Внутри: защита от дрейфа контекста, эпистемические маркеры (борьба с галлюцинациями), встроенная хаос-машина и нулевая терпимость к говнокоду. Модель не просто отвечает на вопросы, она фильтрует вашу логику и заставляет думать до первых принципов.
